# Fruit Forwarder 0.1.0

Fruit Forwarder is an early release candidate for bridging selected Apple
Reminders and read-only Calendar data into Home Assistant and trusted local
stdio MCP clients.

## Included

- Native macOS EventKit access without storing an Apple password.
- Explicit Reminders and Calendar allowlists with independent permissions.
- Home Assistant todo entities, read-only calendar entities, queued mutations,
  stale-snapshot visibility, and explicit recovery for uncertain writes.
- Local MCP tools for scoped reminder mutations and bounded reminder/calendar
  reads, with an optional read-only policy.
- Versioned macOS and MCPB artifacts, deterministic HACS export, checksums,
  source provenance, and guarded publication workflows.

## Known limitations

This is a pre-release. Background macOS permission and reboot/lifecycle
behavior, real-account mutation and calendar fixtures, independent MCP-client
installation, full installed Home Assistant lifecycle, Developer ID signing,
notarization, and ecosystem publication still require the acceptance evidence
described in `docs/acceptance-evidence.md`.

Network MCP, Calendar writes, reminder deletion/list management, Find My, and
other iCloud services are outside this release's supported scope.

## Verification

The candidate is prepared from one clean source revision with the baseline and
current Home Assistant test lanes, Go race/vet checks, secret scanning,
deterministic HACS validation, macOS package validation, MCPB validation, and a
unified release manifest. The candidate's exact source revision and artifact
hashes are recorded in `dist/release-manifest.json` during release preparation.
