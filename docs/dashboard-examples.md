# Home Assistant dashboard examples

Fruit Forwarder creates one Home Assistant todo entity per configured reminder
list and one read-only calendar entity per configured EventKit calendar. Entity
IDs are generated by Home Assistant, so replace the example IDs below with the
IDs shown under **Settings → Devices & services → Fruit Forwarder**.

## Household reminders and calendar

The standard cards require no custom Lovelace resources:

```yaml
type: vertical-stack
cards:
  - type: todo-list
    entity: todo.icloud_reminders_on_dean_groceries
    title: Groceries
  - type: calendar
    entities:
      - calendar.icloud_reminders_on_dean_personal
    initial_view: listWeek
```

The todo card can create items and mark them complete or incomplete. Those
changes are queued for the Mac bridge and remain subject to the configured
reminder-list allowlist. Calendar cards display the last confirmed read-only
window; they do not create, edit, invite, or delete calendar events.

## Multiple lists and calendars

Use separate cards when different household lists have different audiences:

```yaml
type: grid
columns: 2
cards:
  - type: todo-list
    entity: todo.icloud_reminders_on_dean_groceries
    title: Groceries
  - type: todo-list
    entity: todo.icloud_reminders_on_dean_household
    title: Household
  - type: calendar
    entities:
      - calendar.icloud_reminders_on_dean_personal
      - calendar.icloud_reminders_on_dean_family
    initial_view: listWeek
```

If a configured calendar is temporarily unavailable, Fruit Forwarder keeps the
last confirmed calendar snapshot and reports its calendar sync health; a
calendar failure does not discard healthy reminder updates. A query outside the
configured calendar window is rejected rather than presented as complete data.

## Dashboard safety notes

- Use only entity IDs from the configured Fruit Forwarder device; do not paste
  private EventKit IDs, pairing tokens, or household titles into public issue
  reports.
- Keep dashboards scoped to the lists and calendars intentionally exposed in
  the integration entry. A dashboard card does not create an additional
  Apple-level permission boundary.
- For a reminders-only setup, omit the calendar card and leave the calendar
  scope empty. Calendar access is independently opt-in.
- For stale or pending changes, inspect `sync_status`, `sync_age_seconds`, and
  `pending_commands`, then follow the recovery and health guidance in
  [setup.md](setup.md) and [command-lifecycle.md](command-lifecycle.md).
